# Power-BI_Insurance-Anlaytics_dashboard_-Project
A Power BI dashboard designed to track insurance sales performance, opportunities, and employee productivity. It provides a clear snapshot of KPIs, revenue stages, and product distribution to support branch-level decision making.

Features
Key KPIs: Cross Sell, New, Renewal ACH %

Revenue Tracking: Budget vs Branch vs Invoice

Sales Funnel: Revenue by stages (Qualify, Negotiate, etc.)

Employee Activity: Meetings & invoices by account executive

Opportunity Insights: Top opportunities and open opportunities

Product Mix: Distribution across Employee Benefits, Fire, Marine, Engineering, Liability

Tech Stack
Power BI

SQL / DAX for data modeling

Insurance branch datasets
